# Landing Page — Curso de Resina Epóxica (Resinova)

Landing page de conversión para un curso online de resina epóxica (porcelanato líquido),
optimizada para campañas de Meta Ads.

## Estructura

```
landing-resina/
├── index.html      # Página principal
├── styles.css      # Estilos (sin frameworks)
├── script.js       # Interacciones (carruseles, contador, menú, etc.)
└── img/            # Imágenes (logo, trabajos, testimonios, etc.)
```

## Características

- HTML, CSS y JS puros (sin dependencias, carga rápida).
- Totalmente responsive (móvil, tablet, escritorio).
- Video de presentación (Wistia), comparador antes/después, carruseles de
  trabajos y testimonios, contador de oferta, sección de precio y FAQ.
- SEO on-page y datos estructurados (Schema.org).

## Uso

Abre `landing-resina/index.html` en el navegador. No requiere servidor ni build.

## Publicación

Se puede desplegar como sitio estático (GitHub Pages, Netlify, Vercel, etc.).
